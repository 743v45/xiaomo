### 1.2 色彩纪律(硬规则)

- lime **只做强调**:数字高亮、进度、状态点、曲线、徽章底(黑字)。禁止 lime 大面积底、禁止 lime 常规文字。
- violet 做面积不做字:紫底必白字。
- 页面一次最多一处大面积紫(hero/课程卡二选一)。
- 禁彩色 glow(全系统 text-shadow / shadowBlur = 0)。

### 1.3 背景分层系统(v2.1,每部位的底色归属,唯一查询表)

| 层级 | 底色 | 归属部位 |
|---|---|---|
| **L0 页面底** | `#0A0C10` | 页面、导航区(透明融入)、tabBar、列表间隙 |
| **L1 卡片底** | `#14161C` | 一切卡片、列表行、周汇总面板 |
| **L2 嵌入底** | `#1B1E26` | 卡内嵌套块:输入框、进度轨道、课程运行条、chip 默认底、按钮按下态 |
| **L3 纹理底** | L0/L1 + 3% 白点阵或六边形网纹 | 纯装饰,一页 ≤1 处(空状态、hero 背面) |
| **品牌面·紫** | Royal Nebula 渐变(`--violet-2 → --violet → --violet-deep`) | 速度主屏、精选课程卡、完赛 hero、主按钮。**一屏最多一处大面积** |
| **品牌面·lime** | `#EEFF00` 平涂 | 完成徽章、精选卡上的 CTA 按钮。**底必须配黑字,面积 ≤ 按钮/徽章级** |

按下态规则:L0 元素→L1,L1 元素→L2,品牌面紫→亮一档(`--violet-2`),lime→透明度 .7。

### 1.4 色块语义(紫面 vs lime 面)

- **紫面 = 沉浸展示**:内容的主角(当前 Zone、精选课程、完赛成绩),白字 + 白描述(`rgba(255,255,255,.7)`)。
- **lime 面 = 高亮强调**:行动与成就(完成徽章、精选卡 CTA),黑字,小面积。
- 二者不同时出现在同一卡片(紫卡上的按钮用 lime 是唯一合法组合)。
- **渐变纪律(v2.3 收紧)**:品牌紫面一律**纯色平涂 `--violet`**;"渐变"只允许两种:紫系微渐变(明度差 ≤15%,如完赛 hero 顶部淡染)与 lime→lime-soft 进度填充。三段大跨渐变禁止。

### 1.7 玻璃材质(v2.4,来源 liquid-glass-react)

光面之下先有**环境层**:L0 页底放紫/lime 光斑(`.grid-bg` radial 渐变),无光斑则玻璃不可见——这是硬前提。

| 参数 | small(胶囊/控件) | large(卡片/面板) | 来源 |
|---|---|---|---|
| blur | 28rpx(14px) | 40rpx(40px) | materialTokens.regular |
| saturate | 1.15 | 1.3 | 同上 |
| tint 底 | rgba(20,22,28,.55) | 同 | lg-tint(dark) |
| 内暗晕 | inset 0 0 28rpx -22rpx black/.3 | 同 | lg-tint box-shadow |
| 投影 | 0 24rpx 56rpx black/.22 | + 0 64rpx 128rpx black/.3 双层 | glass-shadow(dark large) |
| 描边高光 | 1rpx rgba(255,255,255,.14) | 同 | lg-root border |

- **不可迁移项**:refraction/edge(SVG `feDisplacementMap` 折射形变)——小程序无 SVG 滤镜,永久放弃(shuding/liquid-glass 已验证:其核心即 feDisplacementMap + backdrop url(#filter),全不可用);玻璃感由 blur+sat+tint+高光边承担。
- **v2.4.1 增补(取自 shuding/liquid-glass)**:backdrop 链追加 `contrast(1.15) brightness(1.05)`;顶部内侧暗晕 `inset 0 -20rpx 50rpx black/.15`(玻璃厚度感);边缘透镜高光 = `::before` 上缘 1rpx 白 .55 渐变亮线 + `::after` 下缘白 .18 弱反射线(伪元素是小程序唯一可用的边缘光手法)。
- **分工**:玻璃面 = 信息卡/胶囊(所有 `.hud-panel`);品牌面(Zone hero、精选紫卡)= 实色紫,与玻璃形成材质对比,互不混用。
- 兜底:不支持 backdrop-filter 的环境显示半透明深底,可读性不受影响。
- 素材脚本:光斑在 `.grid-bg` 内置,无需图片。

### 1.6 功率区间色阶(v2.3,全产品视觉骨架)

Coggan Zone 1–7,色值固定不得挪用他处(品牌紫/lime 不参与 Zone 阶):

| Zone | 名 | FTP% | 色值 |
|---|---|---|---|
| Z1 | 恢复 RECOVERY | <55% | `#9CA3AF` |
| Z2 | 耐力 ENDURANCE | 56–75% | `#3B82F6` |
| Z3 | 节奏 TEMPO | 76–90% | `#22C55E` |
| Z4 | 阈值 THRESHOLD | 91–105% | `#EEFF00`(与品牌 lime 同源,Z4 黑字) |
| Z5 | 最大摄氧 VO2 MAX | 106–120% | `#F97316` |
| Z6 | 无氧 ANAEROBIC | 121–150% | `#EF4444` |
| Z7 | 神经肌肉 NEUROMUSCULAR | >150% | `#B91C1C` |

## 3. 排印

### 3.0 字体分工(v2.1)

参考图双字体:Poly Sans(展示)/ Hubot Sans(正文)。小程序不嵌自定义字体,降级映射:

| 角色 | 参考字体 | 小程序实现 |
|---|---|---|
| Display 展示字 | Poly Sans | 系统字 800 字重 + 负字距 -2rpx + line-height 1.15(仅大标题/大数字) |
| Text 正文字 | Hubot Sans | 系统字 400/500,正字距 |

规则:一页 Display 字只出现在 nav 标题和唯一主数据上,其余全 Text。

### 3.2 字重 / 行高 / 字距

- 字重:400 正文 · 500 强调正文 · 600 小标题 · 700 数字与按钮 · 800 大标题(图)
- 行高:数字 1.0 · 标题 1.2 · 正文 1.6 · 多行说明 1.7
- 字距:大数字 **负** -2~-4rpx(图,紧凑);大写标签 **正** +2~+8rpx(图);中文正文 0

### 3.3 数字呈现

- 全部数据数字 `font-variant-numeric: tabular-nums`,700
- 单位与数字同排时:单位 = 数字字号的 0.2 倍、`--txt-2`、大写、+4rpx 字距
- 浮点固定 1~2 位小数,位数全页一致(速度 1 位、距离 2 位)

## 4. 圆角系统 ⭐

### 4.1 阶梯(6 级)

| Token | 值 | 对应组件 | 来源 |
|---|---|---|---|
| `--r-xs` | 8rpx | 进度刻度、极小内嵌块 | 推 |
| `--r-sm` | 16rpx | 时间线节点、小徽章 | 推 |
| `--r-md` | 24rpx | 输入框、列表行内嵌块、课程区段 chip | 图(区段块 ~12px) |
| `--r-lg` | 32rpx | **按钮**(LET'S GO ~16px)、对话框 | 图 |
| `--r-xl` | 40rpx | **卡片**(~20px)、图片卡 | 图 |
| `--r-pill` | 999rpx | chip 标签、进度条、状态胶囊、徽章 | 图(全圆) |

### 4.2 同心圆角公式(嵌套必查)

内层圆角 = 外层圆角 − 内边距,下限 8rpx。
例:卡片 40 内边距 32 → 卡内按钮 ≤ 8;这就是为什么卡片内的进度条/区段块用小圆角。

### 4.3 一致性规则

- 同层级同圆角:所有卡片 40,所有按钮 32,不允许混用。
- 全圆(999)只用于:胶囊类(状态栏/chip/进度条/徽章),方内容禁用 999。

## 5. 间距系统(8 基数)

| Token | 值 | 用途 |
|---|---|---|
| `--sp-1` | 8rpx | 图标-文字、行内最小间隙 |
| `--sp-2` | 16rpx | 组内行距、网格 gap(2 列统计) |
| `--sp-3` | 24rpx | 卡片间距、面板内块距 |
| `--sp-4` | 32rpx | **页面左右边距**、卡片常规内边距 |
| `--sp-5` | 40rpx | 卡片大内边距(标题类) |
| `--sp-6` | 48rpx | 区块纵向分隔 |
| `--sp-8` | 64rpx | 空状态留白 |

4 层规则:页边距 32 → 卡片内 32/40 → 卡片间 24 → 组内 16/8。全站无 4 的倍数之外的魔法数。

## 6. 边框与分隔

- 描边:仅 1rpx `rgba(255,255,255,.08)`(`--line`);高亮描边(选中/进行中)12% 白。
- 分隔优先级:**底色差 > 留白 > 分隔线**;能用前三者就不用线。
- 必须用线时:列表行之间,inset 左 32rpx(与文字对齐),`--line`。
- 卡片默认带 1rpx `--line` 描边(在纯黑底上稳住边缘),这是图的暗卡片质感来源。

## 7. 阴影与发光

- 全系统:**无彩色发光**(禁 text-shadow、禁 canvas shadowBlur)。
- 卡片不投影,靠 `--panel` 与 `--bg` 一档色差 + 描边成立(图)。
- 阴影只给浮层(未来 modal/toast):`0 8rpx 32rpx rgba(0,0,0,.4)`(推)。

## 8. 图标与图形

- **双色策略(v2.1)**:白色图标 = 常规功能;lime 图标 = 强调/完成/能量(参考图 200+ 图标为 lime 单色套)。同一界面白为主、lime 点睛,禁紫色图标。
- 图标:线性,2.5rpx 描边,圆头圆角;徽章/小图形可用 lime 填充 + 黑色内容。
- 图片/插画:统一 `--r-xl` 圆角;插画元素用紫色系 3D 风。
- **纹理(v2.1)**:六边形网纹/3% 白点阵只作 L3 装饰底,一页 ≤1 处(空状态、hero 背面)。
- canvas 曲线:紫面上用白线(`rgba(255,255,255,.92)`)+ 白渐变填充;黑面上用 lime 线 + lime 渐变填充。

## 9. 动效

| Token | 值 | 用途 |
|---|---|---|
| `--dur-fast` | 150ms | 按压反馈(背景色/透明度) |
| `--dur-mid` | 250ms | 展开/收起、chip 切换 |
| `--dur-slow` | 500ms | 进度条宽度、数值面板变化 |
| `--ease` | cubic-bezier(0.22, 1, 0.36, 1) | 全站唯一缓动(ease-out 系) |

- 允许过渡的属性:`background-color / opacity / width / transform`,其余不过渡。
- 数据数字直接替换,不做滚动动画;列表不做逐项入场。

## 10. 状态机

- **主按钮**:default(紫底白字)→ pressed(`--violet-2`)→ disabled(`--panel-2`+灰字)→ 运行中可变体(lime 底黑字 =「强动作」,如课程徽章)。
- **卡片**:default(`--panel`)→ pressed(`--panel-2`,150ms)。
- **连接点**:离线 `--txt-2`;在线 `--lime` + 8rpx 外圈 `rgba(238,255,0,.08)`。
- **chip**:default(panel-2 底灰字)→ 高亮(violet 底白字)→ lime 语义(完成态)。

## 11. 布局

- 单列流;页面左右边距 `--sp-4`(32rpx),全站唯一页边距,一切内容对齐它。
- **Bento 拼贴网格(v2.1)**:统计/成就类内容用混排网格——1 张大卡跨 2 列 + 2 张小卡,卡间距 16rpx,全部 `--r-xl`。用于未来「统计」「成就」页;当前 4 列周汇总保留。
- 网格:副指标 2 列 gap 16;统计 4 列 gap 12。
- 主操作贴底:`margin-top: auto` + 底部安全区(`env(safe-area-inset-bottom)`)。
- **自定义导航(v2.1)**:全站 `navigationStyle: custom`,每页自绘 nav(状态栏 padding + 64rpx 800 大标题),标题融入 L0 底;二级页 nav 左侧加 72rpx 圆形返回钮。
- tabBar:黑底,未选 `--txt-2`,选中 lime,无阴影线(borderStyle black)。
